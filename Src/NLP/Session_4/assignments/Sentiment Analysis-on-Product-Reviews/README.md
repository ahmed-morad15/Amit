#  Sentiment Analysis on IMDb Reviews

##  Project Overview

This project focuses on building a **Sentiment Analysis model** to classify movie reviews as **Positive** or **Negative** using Natural Language Processing (NLP) techniques.

---

##  Objectives

* Clean and preprocess text data
* Convert text into numerical features using **TF-IDF**
* Train a machine learning model for classification
* Evaluate model performance using different metrics
* Visualize insights from the data

---

##  Dataset

* IMDb Movie Reviews Dataset (50,000 reviews)
* Balanced dataset (Positive & Negative reviews)

---

##  Technologies Used

* Python
* Pandas
* NLTK
* Scikit-learn
* Matplotlib & Seaborn

---

##  Workflow

1. Data Loading
2. Text Preprocessing (lowercasing, removing stopwords, cleaning text)
3. Feature Extraction using TF-IDF
4. Train/Test Split
5. Model Training (Logistic Regression & Naive Bayes)
6. Model Evaluation

---

##  Evaluation Metrics

* Accuracy
* Precision, Recall, F1-score
* Confusion Matrix

---

##  Visualizations

* Sentiment Distribution
* Confusion Matrix
* ROC Curve
* WordCloud (Positive & Negative words)
* Top influential words

---

##  Results

* Logistic Regression achieved high accuracy (~90%)
* Naive Bayes provided a good baseline for comparison

---

##  Key Insights

* TF-IDF with n-grams improves performance
* Certain keywords strongly influence sentiment prediction
* Model performs well on balanced datasets
